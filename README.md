Репозиторий существует только ради неё. Основной репозиторий игры приватный, а GitHub Pages
на приватном репозитории — платная функция, поэтому наружу вынесена одна страница, а не код.

**Источник текста — `docs/privacy/index.html` в репозитории игры.** Правьте там, потом
копируйте сюда и обновляйте дату вверху страницы.
